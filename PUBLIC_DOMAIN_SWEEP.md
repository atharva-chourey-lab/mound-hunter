# PUBLIC-DOMAIN CLEAN SWEEP — Mound Hunter Town Sweep

**Date:** 2026-11-17
**Scope:** Every site / look-place in `TOWN_SWEEP.md` (sections A–G + summary table), audited against Atharva's standing filter.
**Filter (his rule, set 2026-11-17):** the public domain must be empty *by construction*. A candidate counts only if there is NO gazetteer entry, ASI listing, tourism page, Wikipedia / Google-Maps label, or old report already fixing it in print. Re-measuring or re-locating published material is a fact-check, not a discovery = junk.

## The criterion that decides the borderline cases

"Fixed in the public domain" = a **coordinate-grade fix**: a lat/lon, a map pin, or a site plan that lets a stranger walk to the spot.

A textual relative description alone ("3 miles south of town", "half a mile east of the town") = the site is *named* but never *fixed* → Bucket 2, and a derived coordinate box is the first actual fix.

An ASI name-only listing (e.g. "Ancient Mound — Undasa") is **not** a fix by itself; it becomes one only when combined with a public pin, coordinates, or an active official survey on the ground.

## THE TWO SPECIFIC QUESTIONS

### Q1 — "Boudh stup" pin: does ANY public source describe a Buddhist stupa at/near Sawda–Chhoti Kasrawad, apart from the Google label itself?

**No.** Exact-phrase search `"Boudh stup" Kasrawad` returns only Kathmandu's Boudhanath. Searches on Sawda / Savda / Chhoti Kasrawad + stupa return only generic stupa material. No local tourism page, MP archaeology page, blog, or paper found describes a Buddhist stupa there. (The town sweep's own textual check reached the same result independently.)

So the label stands **completely alone** in the public record: the pin fixes a *location* publicly (hence Bucket 1 for location), but the *claim* attached to it — that a Buddhist stupa stands there — is supported by no public source at all, and whether the pin is Itbardi under a local name is an open, unpublished question. Treat the pin as an unverified label, not as a located site.

### Q2 — Sujawa and Samantukhera: do they appear ONLY in the Gwalior State 1940-41 report and nowhere else in print since?

**Confirmed, within web-search limits.**

- **Samantukhera:** the only hits are two archive.org copies of the *same* document — the Gwalior State Annual Administration Report 1940-41 (https://archive.org/download/dli.ministry.09258/27334_text.pdf and https://archive.org/download/in.gov.ignca.27334/27334_text.pdf). A name-variant search ("Samantu Khera") returns only unrelated villages. Nothing later: no print, no Wikipedia, no ASI/state listing, no coordinates.
- **Sujawa:** exact-name searches (Sujawa / Suijawa) return **zero** relevant hits at all. It appears only inside that same 1940-41 report (¶84 + Appendix E, per the sweep's reading of it). Nothing else in print since.

Caveat, stated plainly: this is a web + archive.org search result, not a library-catalogue proof of non-existence. But on the evidence available, both names have exactly one print appearance, 85 years ago, with no fix — which is precisely the empty-by-construction profile.

## JUNK HEADLINERS — stop spending on these

1. **Vaishya Tekri** — the worst offender. ASI-listed, excavated 1938–39, publicly pinned, in revenue records (Khasra 275, Andasa) — and as of Oct–Nov 2026 the ASI is *on the mound* with GPR and a sanctioned fresh excavation. Any further spend here is re-measuring an active official dig.
2. **Navdatoli** — Wikipedia's coordinates are the sweep's own "best pin", digit for digit.
3. **Kutwar / Kantipuri** — a famous excavated site with a 1957 ASI catalogue and published identification.
4. **The three Chambal controls (Bateshwar, Kakanmath, Ater Fort)** — all Wikipedia/UNESCO coordinate-published. They did their job (grading the derivation method); they are not targets.
5. **Mahishmati / Maheshwar town mound, Garhkalika, Bhairogarh, Nagari Mata** — known, located, in every guidebook and plan document.
6. **Pipri** — ASI is publicising its own excavations there on Instagram (June 2025). Nothing left to "find".
7. **"Boudh stup" pin (as a location)** — Google already labels it. The open question there is what the label *means*, not where it is.

## Method note

Classifications rest on web search + archive.org full-text + ASI/Wikipedia/UNESCO sources as of 2026-11-17. A Bucket 2/3 classification means "no fixing source found", not a proof that none exists anywhere (un-digitised district records and Hindi local histories are the known blind spots — Kumhar Tekri's Hindi excavation detail shows that literature exists). One credible fixing source, if produced, demotes a survivor immediately — that is the filter working as intended.
